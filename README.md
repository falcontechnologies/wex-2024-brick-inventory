# wex-2024-brick-inventory
Work Experience Rebrickable Database Service

A system to capture the Rebrickable data set from https://rebrickable.com/downloads/
on a schedule, import the changed values to a Postgresql database and archive the
changed files.

## Table of Contents

## Feature Set

The features of this project are:
- The ability to connect to the source data set periodically
- The ability to download the files found of the data set
- The ability to compare the current data set with the previous data set
- The ability to extract, transform and add/replace existing entities and attributes from this set in a database
- The ability to query the database for entities and rows based on entity attributes in a simple web form
- Any additional abilities to make this a resilient service such as configurable properties and appropriate testing and logging.
- The ability to access the information from an API for a web browser interface.

## Technologies

### Backend

The backend process will be a Java application with a Postgresql database. Technologies include:
- OpenJDK Java 17
- Maven
- Any desktop/cloud system like a laptop, desktop or cloud development environment
- Appropriate Linux-like system, shell and terminal. This can include Windows 10/11 with WSL or Mac OSX with Homebrew
- Postgres 16

### Frontend

Once a command-line service has been created, a simple web application using Javascript will be created.
